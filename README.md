# 步態互動實驗室 Gait Interactive Lab

課堂用的 3D 步態教學工具。把四個公開研究資料集的實測關節角度，套在真實的骨骼網格上播放，可以轉視角、拉時間軸、把不同族群擺在一起比對。

**瀏覽器直接開，不需安裝。**首次開啟要下載約 1.6 MB 的骨骼網格（畫面會顯示載入提示），之後由瀏覽器快取，開啟即時。
離線使用請把 `index.html` 與 `three.min.js` 放在同一個資料夾。

👉 **[線上開啟](https://lkkptpt.github.io/gait-interactive-lab/)**

---

## 這是什麼，不是什麼

**是**：24 個片段的實測步態資料播放器，給教練與學生看「真實的步態長什麼樣子」。

**不是**：

- 不是步態模擬器——沒有任何動作是算出來或畫出來的
- 不是評估工具——不能拿來判讀個案
- 不是常模——每個片段的 n 數與族群寫在介面上，自己看

## 哪些是實測值，哪些不是

這是本專案的核心原則：**凡是模型或推論，介面上一律標示，不與量測值混在一起。**

**實測**：所有關節角度、各資料集自身提供的事件與時空參數、臨床分類（醫師或專家判定）

**推得值（介面上會標）**：

- **髖角度偏移**——髖角度是相對骨盆量測的，各資料集零位不同，直接套用腳會搆不到地。每個片段施加一個常數偏移，取值為「使站立期貼地高度變化最小」的幾何閉合條件。此偏移為常數，不影響擺幅與所有組間比較。
- **骨盆垂直與側向位移**——由「站立腳不可穿地、不可側滑」的閉合條件求得，非量測值。
- **站立期比例**——部分資料集未提供離地事件，介面會標示該數值的來源。
- **週期長度**——部分資料集無絕對時間軸，播放速度標示為「未知，1× 不代表實際步速」。

**模型疊加（預設關閉或明確標示）**：膝關節螺旋回鎖、蹠趾關節動作、距下關節軸。這三者沒有任何資料集追蹤，是依文獻參數做的可調模型。

**不顯示的東西**：骨盆與腰椎只取相對週期平均的變化量，所以**擺幅是實測的，絕對角度不是**——不可用本工具判讀某人的骨盆前傾有幾度。

## 已知限制

- 骨頭以剛體旋轉，無關節面滑動、軟骨、韌帶、關節囊、肌肉
- 無前後方向的水平位移（原地踏步），側向有閉合但站立期末的卸載段仍會移動
- 距下關節以正交軸近似，尚未採用 Inman 斜軸
- 骨架為單一成人標本，套用不同體型受試者的角度時，絕對位移量僅供參考
- 骨骼網格已減面（總面數降為原始的 44.7%），極近距離檢視時可見多邊形稜線；
  下肢保留較多面數，胸廓與頭顱減量較多

## 自己建置

```bash
python3 build/build.py          # 產生 index.html
```

改完模板之後，發佈前跑三道檢查：

```bash
python3 build/check_build.py index.html    # 41 個函式定義是否齊全
python3 build/check_cycles.py index.html   # 呼叫環是否都有阻斷旗標
node --check <(抽出 <script> 內容)          # JS 語法
```

這三道不是裝飾。`check_build.py` 是因為一次字串取代把三個函式刪掉才寫的；
`check_cycles.py` 是因為一次無窮遞迴才寫的，而且兩支都拿當時壞掉的版本驗證過會擋下來。
